# Panic Mode

Chrome 확장 프로그램 MVP입니다. 단축키로 열린 일반 Chrome 창을 최소화하고 위장 화면을 표시하며, 기존 탭을 음소거합니다. 다시 실행하면 창과 음소거를 가능한 범위에서 이전 상태로 되돌립니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `panic-mode` 폴더를 선택합니다.
4. 확장 프로그램 메뉴에서 Panic Mode를 고정하면 설정을 쉽게 열 수 있습니다.

## 사용

- 기본 단축키는 **Ctrl+Shift+5**입니다. Chrome이 활성화된 상태에서 누르고, 다시 누르면 복구됩니다. 다른 프로그램이나 운영체제가 단축키를 사용하면 `chrome://extensions/shortcuts`에서 변경하세요.
- 확장 프로그램 팝업에서 스프레드시트, 코드 에디터, iOS 업데이트 또는 Windows 업데이트 화면을 선택할 수 있습니다. 선택은 다음 실행부터 적용됩니다. 팝업의 버튼으로도 위장과 복구를 실행할 수 있습니다.
- 위장 창을 직접 닫아도 기존 창과 음소거 상태를 복구합니다. 위장 창에 별도로 추가한 다른 탭은 복구 시 닫지 않습니다.
- 업데이트 화면은 실제 업데이트를 수행하지 않는 모의 화면입니다. 업데이트 스타일은 탭 표시줄이 없는 팝업 창으로 전체 화면에 표시하며 동일한 단축키로 복구할 수 있습니다. macOS에서는 마우스를 화면 맨 위에 두면 시스템 메뉴가 나타날 수 있습니다.
- 시트와 코드는 겉모습을 재현한 임시 화면입니다. 편집 내용은 저장되지 않으며, 수식·메뉴·실제 파일 기능은 제공하지 않습니다.

## 범위와 주의

- 미디어는 일시정지하지 않고 탭을 음소거합니다. 재생은 계속되며, Chrome 밖의 앱 소리는 제어하지 않습니다.
- 기존에 음소거된 탭과 이미 최소화된 창은 그대로 둡니다. 복구 전에 탭이나 창을 닫거나 상태를 직접 바꾸면 복구가 제한될 수 있습니다.
- 일반 Chrome 창을 대상으로 합니다. 시크릿 창은 별도의 확장 프로그램 허용 설정 및 Chrome의 정책에 따라 동작이 달라질 수 있습니다.
- 위장 화면과 기존 탭은 Chrome UI, 작업 전환기, 알림 등에서 완전히 감춰지지 않습니다. 확장 프로그램을 끄거나 Chrome을 종료하면 진행 중인 위장 상태가 자동 복구된다고 보장할 수 없습니다.
- 실제 웹사이트/파일 표시, 사이트별 예외, Notion/PDF 스타일은 이 MVP에 포함하지 않았습니다.
